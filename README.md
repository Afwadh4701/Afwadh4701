### 🌾 Autonomous Navigation & Safety-Aware Velocity Regulation
**MSc Dissertation · Heriot-Watt University · 2026**

Developed a ROS1 Noetic and Gazebo 11 autonomous-navigation framework for a Jackal-type wheeled UGV operating in simulated uneven, soft-sand and rutted agricultural terrain.

- Integrated **move_base, Navfn, DWA and TEB** for autonomous navigation.
- Implemented a **Python terrain-risk monitor and safety-aware velocity supervisor**.
- Used commanded vs. achieved velocity, slip proxy and motion roughness to regulate DWA velocity and acceleration limits through `dynamic_reconfigure`.
- Designed repeatable experiments using **RViz, rosbag and Python-based analysis**.
- Evaluated mission completion, path length, goal accuracy, velocity and terrain-interaction behaviour.

**Tech:** ROS1 Noetic · Gazebo 11 · Python · RViz · rosbag · DWA · TEB · Navfn
